Ghost Fresh v1.0A - Dashboard only

Open index.html on your phone/browser.
This build is intentionally clean and modular:
- css/app.css = global theme and navigation
- css/dashboard.css = dashboard only
- js/app.js = lightweight routing
- js/dashboard.js = dashboard-only behaviour
- assets/icons = uploaded dashboard/nav icons
- assets/logo = uploaded Ghost header logo

Next modules can be added one at a time without editing the dashboard files.
